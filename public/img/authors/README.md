# Author photos

The site references `/img/authors/nunzio.jpg`.

## Drop the photo here

1. From your LinkedIn profile (https://www.linkedin.com/in/nunzio-cocciolo-a51064115/):
   - Click your profile photo → "Download photo"
2. Crop it square (400×400 minimum is fine, 800×800 ideal)
3. Save as `nunzio.jpg` (JPG, not PNG — smaller)
4. Place it at `public/img/authors/nunzio.jpg`

The image is used in:
- `/about` hero — 160×160 (5 locales)
- Each blog post author card — 64×64
- Open Graph / Twitter card image on `/about` page
- Schema.org `Person.image` (Google Knowledge Graph signal)

If the file is missing the build still works, but the placeholder background shows instead.
